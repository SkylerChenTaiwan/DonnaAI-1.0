# 測試數據檔案說明

此目錄包含用於測試多模態輸入系統的範例 CSV 檔案。

## 檔案說明

### customers-sample.csv
完整正確的客戶數據範例，包含：
- 10筆台灣科技業客戶數據
- 包含所有標準欄位：姓名、公司、電子郵件、電話、產業、地址、備註、標籤
- 適合測試正常的CSV導入流程

### customers-sample-with-errors.csv  
包含各種錯誤的客戶數據，用於測試錯誤處理：
- 缺少必填欄位（姓名、公司名稱為空）
- 無效的電子郵件格式
- 完全空白的行
- 適合測試數據驗證和錯誤報告功能

### records-sample.csv
會議和客戶互動紀錄範例：
- 5筆不同類型的客戶互動紀錄
- 包含會議紀錄、電話紀錄、客戶拜訪等
- 關聯到客戶數據進行測試
- 適合測試紀錄創建和客戶關聯功能

### tasks-sample.csv  
任務和待辦事項範例：
- 8筆不同優先級和狀態的任務
- 包含任務描述、負責人、截止日期等
- 關聯到客戶和紀錄數據
- 適合測試任務創建和管理功能

## 使用方式

1. **CSV導入測試**：使用 `customers-sample.csv` 測試正常的批量導入功能
2. **錯誤處理測試**：使用 `customers-sample-with-errors.csv` 測試驗證和錯誤處理
3. **關聯數據測試**：使用 `records-sample.csv` 和 `tasks-sample.csv` 測試跨數據類型的關聯功能
4. **大量數據測試**：可以複製現有數據創建更大的測試檔案

## 數據格式說明

### 客戶數據欄位
- `name` (必填): 聯絡人姓名
- `company` (必填): 公司名稱  
- `email` (選填): 電子郵件地址
- `phone` (選填): 電話號碼
- `industry` (選填): 所屬產業
- `address` (選填): 地址
- `notes` (選填): 備註資訊
- `tags` (選填): 標籤，使用分號分隔

### 標籤格式
標籤使用分號(`;`)分隔，例如：`VIP;大客戶;技術合作`

### 日期格式  
日期使用 ISO 格式：`YYYY-MM-DD`，例如：`2025-01-15`

## 注意事項

- CSV檔案使用UTF-8編碼，確保中文字元正確顯示
- 欄位名稱需要與系統定義完全一致
- 空值和null值的處理請參考系統驗證規則
- 大檔案測試時請注意記憶體使用量
