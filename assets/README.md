# 資產目錄

此目錄包含應用程式所需的所有靜態資產。

## 必需的檔案

請在此目錄中添加以下檔案：

- `icon.png` - 應用程式圖標 (1024x1024 像素)
- `splash.png` - 啟動畫面圖片 (1920x1080 像素，建議)
- `adaptive-icon.png` - Android 自適應圖標 (1024x1024 像素)
- `favicon.png` - Web 版本的網站圖標 (48x48 像素)

## 圖標設計指南

1. **icon.png**: 
   - 大小：1024x1024 像素
   - 格式：PNG
   - 背景：透明或純色
   - 用於 iOS 和 Android 應用圖標

2. **splash.png**:
   - 大小：1920x1080 像素（或更高）
   - 格式：PNG
   - 將自動調整大小以適應不同的設備

3. **adaptive-icon.png**:
   - 大小：1024x1024 像素
   - 格式：PNG
   - Android 8.0+ 的自適應圖標前景層

4. **favicon.png**:
   - 大小：48x48 像素
   - 格式：PNG
   - 用於 Web 版本
