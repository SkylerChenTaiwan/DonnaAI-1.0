# App Store 審核改善計畫

根據 2024-2025 年最新審核案例分析，以下是針對 DonnaAI 需要立即執行的改善措施。

## 🔥 立即需要改善的項目

### 1. 優化權限說明文字

#### 現況
```
NSMicrophoneUsageDescription: "此應用需要錄音權限來記錄會議內容，協助您進行會議記錄和智能分析。"
```

#### 改善後
```
NSMicrophoneUsageDescription: "DonnaAI 需要您的錄音權限來記錄會議音訊，並透過 AI 技術自動轉換為文字筆記。您的錄音將安全儲存且僅在您主動使用錄音功能時才會存取麥克風。"
```

### 2. 加強網路錯誤處理和重試機制

雖然已有離線支援，但需要加強網路錯誤時的使用者體驗：

#### 需要新增的功能：
1. **網路狀態顯示器** - 在應用程式頂部顯示網路狀態
2. **重試按鈕** - 所有網路請求失敗時顯示重試選項
3. **離線模式提示** - 明確告知使用者目前處於離線狀態

### 3. 審核說明優化

在 App Store Connect 的審核備註中加入：

```
審核建議：
1. 如遇到網路連線問題，請嘗試使用行動數據或切換到不同的 WiFi 網路
2. 測試帳號已預載範例資料，可直接測試所有功能
3. 錄音功能需要真實設備測試，模擬器無法正常運作
4. AI 分析可能需要 10-30 秒處理時間，請耐心等待
5. 本應用使用 Firebase 服務（位於亞洲地區），可能需要特定網路配置
```

### 4. 測試帳號準備

```
帳號：reviewer@donnaai.app
密碼：ReviewTest2025!

預載資料：
- 5 個範例客戶
- 10 筆會議記錄
- 3 個待辦任務
- 2 份 AI 分析報告
```

## 🚨 避免觸發審核紅旗的注意事項

1. **不要在截圖中顯示**
   - 其他品牌的 Logo 或名稱
   - 未經授權的商標
   - 測試或開發中的功能

2. **確保所有功能可用**
   - 所有按鈕都要有功能
   - 不要有 "Coming Soon" 的功能
   - 不要有空白頁面

3. **資料完整性**
   - 預載足夠的測試資料
   - 避免空狀態畫面
   - 提供清楚的使用引導
