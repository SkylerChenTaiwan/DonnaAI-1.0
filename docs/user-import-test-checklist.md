# 用戶匯入功能測試檢查清單

測試網址：https://donnaai-5e601.web.app

## 準備工作
- [ ] 準備測試檔案：test-data/test-users.csv 和 test-users-2.csv
- [ ] 登入 Super Admin 帳號
- [ ] 進入組織管理 > 新增組織

## 測試場景 1：簡易模式（單檔案）

### 1.1 檔案上傳
- [ ] 點擊「智能用戶匯入」
- [ ] 確認預設為「簡易模式」
- [ ] 上傳 test-users.csv
- [ ] 檢查檔案資訊顯示（5列 × 5欄）
- [ ] 確認沒有顯示合併選項

### 1.2 欄位對應
- [ ] 點擊「下一步」進入欄位對應
- [ ] 檢查來源欄位是否正確顯示：姓名、電子郵件、部門、職位、電話
- [ ] 確認目標欄位選項：電子郵件、姓名、角色、部門、職位、電話號碼
- [ ] 進行欄位映射：
  - 姓名 → 姓名
  - 電子郵件 → 電子郵件
  - 部門 → 部門
  - 職位 → 職位
  - 電話 → 電話號碼

### 1.3 預覽匯入
- [ ] 點擊「下一步」進入預覽
- [ ] 檢查 5 筆資料是否正確顯示
- [ ] 確認資料驗證狀態（應該都是有效）
- [ ] 點擊「開始匯入」
- [ ] 檢查匯入結果

## 測試場景 2：進階模式（多檔案合併）

### 2.1 切換到進階模式
- [ ] 重新開始匯入流程
- [ ] 切換到「進階模式」
- [ ] 上傳 test-users.csv
- [ ] 上傳 test-users-2.csv
- [ ] 檢查兩個檔案都顯示

### 2.2 關鍵欄位選擇
- [ ] 為第一個檔案選擇關鍵欄位：電子郵件
- [ ] 為第二個檔案選擇關鍵欄位：Email
- [ ] 確認「預覽及合併」按鈕出現

### 2.3 檔案合併
- [ ] 點擊「預覽及合併」
- [ ] 檢查合併結果預覽
- [ ] 確認合併統計（總筆數、匹配筆數）
- [ ] 點擊「下一步」

### 2.4 合併後的欄位對應
- [ ] 檢查來源欄位是否包含兩個檔案的所有欄位
- [ ] 進行欄位映射
- [ ] 點擊「下一步」預覽
- [ ] 檢查合併後的資料

## 測試場景 3：錯誤處理

### 3.1 無效檔案
- [ ] 嘗試上傳非 CSV 檔案（如 .txt）
- [ ] 確認顯示錯誤訊息

### 3.2 空檔案
- [ ] 建立並上傳空的 CSV 檔案
- [ ] 確認顯示「檔案內容為空」錯誤

### 3.3 重複資料
- [ ] 上傳包含重複 email 的檔案
- [ ] 確認在預覽階段顯示重複警告
