# Notion 資料庫快捷鍵文檔

## 基本導航
| 快捷鍵 | 功能 | 備註 |
|--------|------|------|
| `↑` `↓` `←` `→` | 上下左右移動選中儲存格 | 基本導航 |
| `Tab` | 移到右邊儲存格 | 到行尾會換行 |
| `Shift + Tab` | 移到左邊儲存格 | 到行首會換到上一行 |
| `Enter` | 向下移動或開始編輯 | 選中狀態按 Enter 進入編輯 |
| `Home` | 移到當前行第一格 | - |
| `End` | 移到當前行最後一格 | - |
| `Ctrl/Cmd + Home` | 移到表格第一格 | - |
| `Ctrl/Cmd + End` | 移到表格最後一格 | - |
| `Page Up` | 向上翻頁 | - |
| `Page Down` | 向下翻頁 | - |

## 編輯操作
| 快捷鍵 | 功能 | 備註 |
|--------|------|------|
| `F2` | 進入編輯模式 | 與 Excel 相同 |
| `Enter` | 在選中時進入編輯 | 編輯中按 Enter 確認並向下 |
| `Escape` | 取消編輯 | 恢復原值 |
| `Delete` | 清空儲存格內容 | 不進入編輯模式 |
| `Backspace` | 清空並進入編輯 | macOS 上是 Delete 鍵 |
| 輸入任意字元 | 覆蓋並進入編輯 | 直接開始輸入 |

## 選擇操作
| 快捷鍵 | 功能 | 備註 |
|--------|------|------|
| `Shift + 方向鍵` | 擴展選擇範圍 | 多選儲存格 |
| `Ctrl/Cmd + A` | 選擇整個表格 | - |
| `Ctrl/Cmd + Space` | 選擇整列 | - |
| `Shift + Space` | 選擇整行 | - |
| `Ctrl/Cmd + Click` | 添加到選擇 | 不連續選擇 |

## 複製貼上
| 快捷鍵 | 功能 | 備註 |
|--------|------|------|
| `Ctrl/Cmd + C` | 複製 | 支援多格複製 |
| `Ctrl/Cmd + X` | 剪下 | - |
| `Ctrl/Cmd + V` | 貼上 | 智能貼上格式 |
| `Ctrl/Cmd + Shift + V` | 純文字貼上 | 不含格式 |

## 搜尋與取代
| 快捷鍵 | 功能 | 備註 |
|--------|------|------|
| `Ctrl/Cmd + F` | 搜尋 | 在當前視圖搜尋 |
| `Ctrl/Cmd + H` | 取代 | 搜尋並取代 |
| `F3` / `Ctrl/Cmd + G` | 尋找下一個 | - |
| `Shift + F3` / `Ctrl/Cmd + Shift + G` | 尋找上一個 | - |

## 撤銷重做
| 快捷鍵 | 功能 | 備註 |
|--------|------|------|
| `Ctrl/Cmd + Z` | 撤銷 | - |
| `Ctrl/Cmd + Y` / `Ctrl/Cmd + Shift + Z` | 重做 | - |

## 特殊功能
| 快捷鍵 | 功能 | 備註 |
|--------|------|------|
| `Ctrl/Cmd + D` | 向下填充 | 複製上方儲存格內容 |
| `Ctrl/Cmd + R` | 向右填充 | 複製左方儲存格內容 |
| `Ctrl/Cmd + Enter` | 在同一格換行 | 多行文字 |
| `Alt + Enter` | 在編輯時換行 | Windows |

## 日期快捷輸入
在日期欄位中支援自然語言輸入：
- `today` / `今天` → 今天的日期
- `tomorrow` / `明天` → 明天的日期
- `yesterday` / `昨天` → 昨天的日期
- `next monday` / `下週一` → 下個週一
- `+7` → 7 天後
- `-3` → 3 天前

## 選擇框快捷鍵
在選擇框（Select）欄位：
- 開始輸入可搜尋選項
- `↑` `↓` 選擇選項
- `Enter` 確認選擇
- `Escape` 取消選擇

## 多選標籤快捷鍵
在多選標籤欄位：
- `Space` 切換當前標籤選中狀態
- `,` 分隔多個標籤輸入
- `Backspace` 刪除最後一個標籤
