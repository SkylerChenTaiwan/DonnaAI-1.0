# Notion 資料庫編輯行為研究

## 1. 儲存格編輯流程

### 基本互動
- **單擊**: 選中儲存格（藍色邊框）
- **雙擊**: 進入編輯模式
- **F2**: 也可進入編輯模式
- **Enter**: 在選中狀態下進入編輯模式

### 編輯狀態
- 編輯框直接覆蓋在儲存格上
- 沒有額外的彈出框或模態框
- 編輯框有 2px 藍色邊框
- 背景保持白色，無陰影

### 儲存行為
- 失去焦點時自動儲存
- Enter 確認並移到下一格
- Tab 確認並移到右邊
- Escape 取消編輯

## 2. 視覺狀態

### 儲存格狀態
1. **預設**: 無邊框，白色背景
2. **懸停**: 淺灰背景 (#f7f6f3)
3. **選中**: 2px 藍色邊框 (#0a84ff)
4. **編輯中**: 2px 藍色邊框，白色背景

### 過渡動畫
- 背景色過渡: 150ms ease
- 邊框出現: 無動畫，立即顯示
- 編輯框出現: 無動畫，立即顯示

## 3. 鍵盤導航

### 基本導航
- **方向鍵**: 上下左右移動
- **Tab/Shift+Tab**: 水平移動
- **Enter**: 垂直向下移動
- **Home/End**: 移到行首/行尾
- **Ctrl+Home/End**: 移到表格首/尾

### 編輯模式快捷鍵
- **F2/Enter**: 進入編輯
- **Escape**: 取消編輯
- **Tab**: 儲存並移到下一格
- **Shift+Tab**: 儲存並移到上一格

## 4. 特殊屬性編輯器

### 選擇框
- 點擊後顯示下拉選單
- 可以直接輸入搜尋
- 支援鍵盤上下選擇

### 日期選擇器
- 點擊顯示日曆
- 支援直接輸入日期
- 智能解析自然語言

### 標籤編輯器
- 點擊顯示標籤列表
- 支援多選
- 可以新建標籤

## 5. 效能要求

### 響應時間
- 點擊到選中: < 16ms
- 雙擊到編輯: < 50ms
- 輸入延遲: < 16ms
- 自動儲存延遲: 500ms

### 滾動性能
- 60 FPS 滾動
- 虛擬滾動優化
- 惰性載入儲存格內容
