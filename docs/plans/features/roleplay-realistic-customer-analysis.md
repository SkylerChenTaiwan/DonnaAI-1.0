# 如何讓 AI 扮演真實客戶 - 核心挑戰分析

## 問題核心：真實客戶的複雜性

### 1. 真實客戶的特徵

**不是理性機器**
- 情緒化反應
- 前後矛盾的說法
- 隱藏真實想法
- 受個人經驗影響

**對話的非線性**
- 突然轉移話題
- 忘記之前說過的話
- 被其他事情干擾
- 有自己的議程

**真實的知識侷限**
- 不懂專業術語
- 誤解產品功能
- 有錯誤的既定印象
- 基於片面資訊決策

### 2. 現有 AI 的限制

**過度理性**
- AI 傾向給出有邏輯的回應
- 不會真的「不講理」
- 難以模擬情緒化決策

**過度配合**
- AI 本能想要幫助
- 容易透露太多資訊
- 不會真的刁難

**知識詛咒**
- AI 知道太多
- 難以模擬無知狀態
- 會不小心用專業術語

## 解決方案：多層次真實性設計

### 1. 資料驅動的角色建模

### 4. 實作方法

**A. 雙層 Prompt 策略**

```javascript
// 第一層：角色限制
const characterPrompt = `
你有以下限制：
1. 你不知道 CRM 和 ERP 的差別
2. 你覺得現在的 Excel 已經夠用
3. 你不相信業務員的話
4. 你的預算其實只有說出來的一半
5. 你老闆說過「不要亂買系統」
`;

// 第二層：對話規則
const dialogueRules = `
對話規則：
1. 絕對不要主動問產品功能
2. 聽到價格就皺眉
3. 每3句話就要提到你很忙
4. 隨機忘記剛剛討論的內容
5. 突然關心奇怪的細節（如：你們公司有幾個人？）
`;
```

**B. 情緒狀態追蹤**

### 5. 訓練資料來源

**真實對話採集**
1. 請資深業務提供失敗案例對話
2. 收集客戶真實的拒絕理由
3. 記錄客戶的非理性行為
4. 整理常見的溝通誤解

**角色原型庫**
- 基於真實客戶建立 10-20 個原型
- 每個原型都有真實的背景故事
- 包含個人喜好和地雷

### 6. 驗證機制

**真實度測試**
1. 讓資深業務對話測試
2. 評估「這像不像真客戶」
3. 收集不真實的地方
4. 持續調整改進

**關鍵指標**
- 對話結束得太順利 = 不真實
- 客戶太理性 = 不真實  
- 資訊給得太完整 = 不真實
- 沒有情緒起伏 = 不真實

## 結論

要做出「夠像真實客戶」的 AI，關鍵不是讓 AI 更聰明，而是要：

1. **限制 AI 的能力** - 模擬無知和偏見
2. **注入不理性** - 情緒化、矛盾、健忘
3. **基於真實資料** - 用實際案例訓練
4. **狀態機制** - 不是單一 prompt
5. **持續優化** - 根據真實度反饋調整

最重要的是：**收集大量真實的失敗對話案例**，這才是讓 AI 表現真實的關鍵。
