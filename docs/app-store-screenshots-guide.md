# App Store 截圖準備指南

## 📱 必要截圖尺寸

### iPhone 截圖（必要）
1. **6.9" (iPhone 15 Pro Max)**
   - 尺寸：1290 x 2796 像素
   - 至少 4 張，最多 10 張

2. **6.5" (iPhone 14 Plus)**
   - 尺寸：1242 x 2688 像素
   - 或使用 6.9" 截圖自動縮放

3. **5.5" (iPhone 8 Plus)**
   - 尺寸：1242 x 2208 像素
   - 支援舊版 iPhone

### iPad 截圖（選擇性但建議）
1. **12.9" (iPad Pro)**
   - 尺寸：2048 x 2732 像素
   - 至少 4 張，最多 10 張

2. **11" (iPad Pro)**
   - 尺寸：1668 x 2388 像素
   - 或使用 12.9" 截圖自動縮放

## 🎨 設計規範

### 文字標註
- **標題字體大小**：60-80pt
- **副標題字體大小**：40-50pt
- **使用品牌顏色**：橘色 (#F97316) 作為強調色
- **背景**：使用淺色背景或漸層

### 設計元素
- 保持簡潔清晰
- 使用真實的應用程式截圖
- 添加手機框架（選擇性）
- 確保文字可讀性

### 本地化
- 準備繁體中文版本（主要）
- 準備英文版本
- 確保文字不會被裁切

## 🛠️ 截圖製作工具

### 推薦工具
1. **Sketch/Figma**
   - 專業設計工具
   - 支援多尺寸輸出

2. **Canva**
   - 線上設計工具
   - 有 App Store 截圖模板

3. **Screenshot**
   - Mac App Store 工具
   - 自動添加裝置框架

### 截圖製作步驟
1. 在實機或模擬器擷取原始截圖
2. 使用設計工具添加標註文字
3. 調整為所需尺寸
4. 輸出為 PNG 格式（無壓縮）

## ✅ 檢查清單

### 技術要求
- [ ] PNG 格式，無壓縮
- [ ] 正確的像素尺寸
- [ ] 無透明背景
- [ ] 檔案大小 < 50MB

### 內容要求
- [ ] 無個人識別資訊
- [ ] 無測試資料
- [ ] 無競爭對手內容
- [ ] 符合 App Store 指南

### 品質要求
- [ ] 高解析度，無模糊
- [ ] 文字清晰可讀
- [ ] 顏色準確
- [ ] 視覺吸引力

## 🚀 上傳步驟

1. 登入 App Store Connect
2. 選擇您的應用程式
3. 進入「媒體管理」
4. 上傳各尺寸截圖
5. 設定顯示順序
6. 儲存變更
