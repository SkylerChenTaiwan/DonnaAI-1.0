# App Store 審核防拒清單 - DonnaAI 專用

基於 2024-2025 年最新的審核案例分析，以下是 DonnaAI 需要特別注意的審核風險和解決方案。

## 🚨 高風險項目（必須解決）

### 1. Firebase 電話認證問題 ❌
**問題**：Firebase 電話認證需要推播通知才能運作，但 Apple 要求推播必須是可選的
**解決方案**：
- [ ] 提供 Email 登入作為主要方式
- [ ] 移除電話認證功能
- [ ] 確保推播通知是可選的

### 2. 網路連線問題 ⚠️
**問題**：Apple 審核環境的 WiFi 常無法連接 Firebase
**解決方案**：
- [ ] 實作離線模式偵測和友善提示
- [ ] 加入「重試」按鈕
- [ ] 在審核說明中提醒審核員可能需要使用行動數據

### 3. 權限說明文字 📝
**當前狀態**：已設定但需要優化
```
現在：此應用需要錄音權限來記錄會議內容，協助您進行會議記錄和智能分析。
建議：DonnaAI 需要您的錄音權限來記錄會議音訊，並透過 AI 技術自動轉換為文字筆記。您的錄音將安全儲存且僅在您主動使用錄音功能時才會存取麥克風。
```

### 4. AI 功能描述限制 🤖
**問題**：不能在截圖或副標題提及 "ChatGPT" 或 "OpenAI"
**解決方案**：
- [ ] 檢查所有截圖，移除品牌名稱
- [ ] 使用「AI 技術」替代特定品牌
- [ ] 在描述中使用通用術語

## ⚠️ 中風險項目（建議改善）

### 5. 類似應用程式（4.3 Spam）
**風險**：CRM 類應用太多可能被視為 Spam
**預防措施**：
- [ ] 強調獨特功能：AI 會議記錄
- [ ] 突出差異化：多模態輸入
- [ ] 避免通用 CRM 描述

### 6. 隱私標籤準確性
**需要聲明的資料收集**：
- [ ] 聯絡資訊（電子郵件）
- [ ] 音訊資料（會議錄音）
- [ ] 使用資料（Analytics）
- [ ] 診斷資料（Crashlytics）
- [ ] 識別符（使用者 ID）
- [ ] 位置（如果使用）

### 7. 第三方 SDK 問題
**潛在問題**：expo-av 可能觸發麥克風權限警告
**解決方案**：
- [ ] 確認 NSMicrophoneUsageDescription 已設定
- [ ] 更新所有 SDK 到最新版本
- [ ] 檢查是否有未使用的權限

## 🔧 特別針對 DonnaAI 的建議

### 1. 強調本地化優勢
- 繁體中文優先
- 台灣在地化功能
- 符合當地商業習慣

### 2. 差異化定位
不要說：「另一個 CRM 應用」

### 3. 避免觸發 Spam 偵測
- 不要提及競爭對手
- 不要使用通用描述
- 強調獨特價值主張

### 4. 準備應對審核問題
常見問題回覆模板：
```
Q: 為什麼需要錄音權限？
A: DonnaAI 的核心功能是將會議錄音自動轉換為結構化筆記，此功能僅在用戶主動點擊錄音按鈕時啟用。

Q: Firebase 連線失敗？
A: 請嘗試切換到行動數據，或點擊重試按鈕。我們的伺服器位於亞洲，可能與審核環境的網路設定有相容性問題。

Q: 這與其他 CRM 有何不同？
A: DonnaAI 專注於 AI 驅動的會議記錄和自動化客戶資料擷取，而非傳統的手動資料輸入 CRM。
```
