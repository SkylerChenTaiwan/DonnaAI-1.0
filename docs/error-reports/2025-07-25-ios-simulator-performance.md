# iOS 模擬器效能問題診斷報告

**日期**: 2025-07-25  
**問題**: iOS 模擬器運行極度緩慢，即使在未執行 APP 時也很慢

## 根本原因分析

### 1. **Metro Bundler 配置問題**
- 最近的 Metro 配置可能導致效能問題
- 檔案監控系統可能消耗過多資源

### 2. **模擬器資源分配**
- iOS 模擬器可能分配了過多或過少的記憶體
- GPU 加速設定可能不正確

### 3. **開發環境問題**
- Watchman 可能有快取問題
- Node.js 進程可能有記憶體洩漏
- 可能有多個開發服務器同時運行

### 4. **系統級問題**
- macOS 可能有背景進程占用資源
- 磁碟空間不足
- 虛擬記憶體交換過度

## 解決方案選項

### 方案 A: 清理並重置開發環境（推薦）
**優點**：
- 徹底解決快取和配置問題
- 不需要修改程式碼

**步驟**：
1. 關閉所有模擬器和開發服務器
2. 清理 Metro 快取
3. 清理 Watchman 狀態
4. 重置模擬器
5. 重新啟動開發環境

### 方案 B: 調整 Metro 配置
**優點**：
- 針對性解決 Metro 相關問題
- 可以優化打包速度

**步驟**：
1. 檢查 metro.config.js 的 watchman 設定
2. 調整檔案監控範圍
3. 啟用快取優化

### 方案 C: 優化模擬器設定
**優點**：
- 直接解決模擬器效能問題
- 可以提升整體開發體驗

**步驟**：
1. 刪除並重新創建模擬器
2. 調整模擬器記憶體分配
3. 確認 GPU 加速已啟用

## 影響評估

- **對開發的影響**：高 - 嚴重影響開發效率
- **對程式碼的影響**：低 - 主要是環境問題
- **緊急程度**：高 - 需要立即解決

## 建議執行順序

1. 先執行方案 A（清理環境）
2. 如果問題持續，執行方案 C（優化模擬器）
3. 最後考慮方案 B（調整 Metro）
