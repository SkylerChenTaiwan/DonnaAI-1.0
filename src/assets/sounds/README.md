# 音效檔案目錄

此目錄應包含以下音效檔案：

## 必要音效檔案

1. **success.mp3** - 成功音效
   - 用於：操作成功完成時
   - 建議：短促、愉悅的提示音（0.5-1秒）
   - 來源建議：freesound.org 搜尋 "success chime"

2. **error.mp3** - 錯誤音效
   - 用於：操作失敗或錯誤時
   - 建議：低沉、短促的警告音（0.5-1秒）
   - 來源建議：freesound.org 搜尋 "error beep"

3. **notification.mp3** - 通知音效
   - 用於：收到新通知或提醒時
   - 建議：清脆、明顯的提示音（0.5-1秒）
   - 來源建議：freesound.org 搜尋 "notification bell"

## 音效規格建議

- 格式：MP3
- 位元率：128 kbps（足夠用於短音效）
- 檔案大小：< 100KB
- 長度：0.5-1秒
- 音量：標準化，避免過大或過小

## 免費音效來源

1. **Freesound.org** - 免費音效庫（需要註冊）
2. **Zapsplat.com** - 免費音效（需要註冊）
3. **系統預設音效** - 可使用 Expo 內建的系統音效

## 暫時解決方案

如果暫時沒有音效檔案，可以創建空的 MP3 檔案：

```bash
# macOS/Linux
touch success.mp3 error.mp3 notification.mp3
```

或使用線上工具生成靜音 MP3 檔案。

## 注意事項

- 確保音效檔案的版權允許商業使用
- 測試音效在不同裝置上的播放效果
- 考慮使用者可能在安靜環境中使用應用程式
