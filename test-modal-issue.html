🔍 Modal 問題診斷工具

問題概述

CustomFieldsModal 在頁面載入時自動顯示（visible: true），即使 showCustomFieldsModal 初始值是 false。

診斷結果

開始診斷...

測試 React State

可能的原因

  • ❌ 熱重載問題: Expo 的熱重載可能保留了舊的狀態
  • ❌ 瀏覽器快取: 舊的 JavaScript 代碼被快取
  • ❌ 條件渲染邏輯: 條件判斷可能有問題
  • ❌ Portal 渲染失敗: ReactDOM.createPortal 無法正常工作

解決方案

  1. 完全清除所有快取：rm -rf .expo node_modules/.cache
  2. 重啟開發伺服器：npx expo start --web --clear
  3. 清除瀏覽器快取：Ctrl+Shift+Del
  4. 使用無痕模式測試
