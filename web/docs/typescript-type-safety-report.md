## 發現並修復的型別錯誤

### 1. 環境變數存取錯誤 (lib/env.ts)
**問題**: `noPropertyAccessFromIndexSignature` 要求使用括號存取 process.env
**修復**: 將所有 `process.env.KEY` 改為 `process.env['KEY']`
**影響**: 37 處修改

### 2. Firebase Admin 初始化錯誤 (lib/firebase-admin.ts)
**問題**: 
- getApps()[0] 可能返回 undefined
- Firestore 文檔資料型別推斷不準確
**修復**:
- 加入非空斷言 `getApps()[0]!`
- 明確型別轉換為 `Record<string, unknown>`
**影響**: 7 處修改

### 3. API 響應介面錯誤 (lib/middleware.ts)
**問題**: `exactOptionalPropertyTypes` 要求明確定義 undefined
**修復**: 將 `field?: string` 改為 `field: string | undefined`
**影響**: 5 個介面定義

### 4. 用戶資料型別推斷錯誤 (app/api/users/route.ts)
**問題**: unknown 型別無法直接賦值給具體型別
**修復**: 使用明確的型別斷言
**影響**: 8 處型別斷言

### 5. Token 驗證響應錯誤 (app/api/auth/verify/route.ts)
**問題**: 可選屬性與 undefined 的處理
**修復**: 統一使用 `string | undefined` 格式
**影響**: 1 個介面定義
